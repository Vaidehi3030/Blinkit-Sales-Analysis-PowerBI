# Blinkit-Sales-Analysis-PowerBI

# Project Overview
This project presents an interactive Power BI dashboard developed to analyze Blinkit's grocery sales performance. The dashboard provides insights into sales, customer ratings, outlet performance, and product categories, enabling stakeholders to make data-driven business decisions.

# Business Problem
Blinkit operates multiple grocery outlets across different locations and outlet sizes. Decision-makers require a centralized dashboard to monitor:
- Total Sales
- Average Sales
- Customer Ratings
- Product Performance
- Outlet Performance
- Sales Distribution
- Outlet Growth Trends
The objective is to identify key business drivers and improve operational decision-making.

# Dataset Information
- Dataset Name: Blinkit Grocery Dataset
- Records: 8,523

# Tools Used
- Microsoft Power BI
- Microsoft Excel
- DAX
- Power Query

# Dashboard Features
- KPI Cards:
    Total Sales
    Average Sales
    Total Items
    Average Rating
    Total Outlets
- Visualizations:
    Sales by Fat Content
    Sales by Item Type
    Sales by Outlet Size
    Sales by Outlet Location
    Outlet Establishment Trend
    Outlet Type Performance Matrix
- Interactive Filters
    Outlet Type
    Outlet Size
    Outlet Location

# Business Insights
- Low Fat products contribute a larger share of sales than Regular products.
- Tier 3 outlets generate the highest sales among outlet locations.
- Fruits & Vegetables and Snack Foods are the top-performing product categories.
- Medium-sized outlets contribute the largest portion of total sales.
- Sales fluctuate across outlet establishment years, indicating varying performance of outlets over time.
